## P0 — fixed

- **Vendor create/edit appeared broken** — `components/vendors/vendor-table.tsx` — After successful server actions, the table never called `router.refresh()`, so the RSC props stayed stale and new rows never appeared. Sheet close from `?new=1` only called `setCreateOpen(false)`, leaving the sheet open while the query param remained. **Change:** `handleMutationSuccess` + `closeCreateSheet` call `router.refresh()` and `handleCreateOpenChange(false)`. **Commit:** `e322772`

- **Manufacturing create/edit/delete stale UI** — `components/manufacturing/manufacturing-view.tsx` — Same missing `router.refresh()` after mutations; empty board could persist after first run. **Change:** Same pattern as vendors. **Commit:** `903dd18`

- **Cron routes returned empty 500 bodies** — `lib/cron-auth.ts`, `app/api/cron/*/route.ts` — Unhandled `MissingCredentialsError` / `Error` produced Next.js stack traces with no JSON body. **Change:** `runCronJob()` wrapper returns `{ ok: false, error: string }` with status 500. **Commit:** `0777124`
